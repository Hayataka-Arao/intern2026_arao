# intern2026_arao
2026年のインターンシップ プロジェクトリポジトリです。Jupyter Notebookを使用したデータ分析とPythonスクリプトを含んでいます。

## 📋 概要

このリポジトリは2026年のインターンシップ期間中に実施したプロジェクトの成果物を管理しています。データ分析と処理に焦点を当てており、作業の大部分はインタラクティブなJupyter Notebookで構成されています。

## 🛠️ 使用技術

- **Jupyter Notebook** (97.9%) - インタラクティブな分析と可視化
- **Python** (1.3%) - サポートスクリプトとユーティリティ
- **その他** (0.8%) - 設定ファイルと補足ファイル

## 📁 プロジェクト構成

```
intern2026_arao/
├── analysis/           # データ分析ノートブックと結果
├── scripts/            # Python ユーティリティスクリプト
├── tools/              # ヘルパーツールとユーティリティ
├── データ結果/          # 結果と出力データ
├── インターンシップ報告.pptx  # インターンシップ報告プレゼンテーション
└── README.md           # このファイル
```

## 📂 ディレクトリガイド

- **`analysis/`** - データの分析、探索、可視化を行う Jupyter Notebook
- **`scripts/`** - 自動化、データ処理、ユーティリティを行う Python スクリプト
- **`tools/`** - プロジェクト全体で使用されるヘルパーモジュールとツール
- **`データ結果/`** - 分析結果と生成されたデータファイルを保存するフォルダ

## 🚀 使い始める

### 必要な環境

- Python 3.x
- Jupyter Notebook
- 必要な Python パッケージ（ノートブック内の依存関係を参照）

### ノートブックの実行方法

1. Jupyter をインストール：
   ```bash
   pip install jupyter
   ```

2. Jupyter Notebook を起動：
   ```bash
   jupyter notebook
   ```

3. `analysis/` ディレクトリに移動し、`.ipynb` ファイルを開く

## 📊 分析内容

このリポジトリには、`analysis/` ディレクトリ内の Jupyter Notebook を通じて探索できるさまざまな分析ワークフローが含まれています。結果と可視化は自動的に生成され、`データ結果/` に保存されます。
